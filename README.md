# RS React Course — React Forms

Training project for [**The Rolling Scopes School**](https://rs.school/) React course.

## About

Application for practicing form handling with:

- Uncontrolled components and React Hook Form
- Accessible modals via React Portals
- Validation with Zod
- Redux Toolkit for submissions and countries list
